# 프로젝트 배경

## 무엇을 만드는가

**주식회사 비하이브코퍼레이션**의 웹사이트. 기존 임대형 홈페이지를 대체한다.

핵심 목표는 하나다 — **방문자가 견적 문의까지 도달하게 하는 것.**
사이트의 모든 구성은 이 전환 지점을 향한다.

## 클라이언트를 오해하지 말 것

이 회사를 "1인 번역 프리랜서"로 잘못 상정하면 설계가 통째로 어긋난다.
실제 모습은 이렇다.

| | 실제 |
|---|---|
| 형태 | **법인** (2024년 법인 전환, 대표이사 임선희) |
| 주력 | **통역이 주력** — 동시 · 순차 · 위스퍼링 |
| 규모 | 800+ 프로젝트 / 100+ 클라이언트 / 통번역 10년 |
| 대표 사업 | 6년 연속 식약처 ICCR 국제협의체 **운영사무국** |
| 그 외 | 국빈 수행 출장, 국제회의 사무국 운영, 기업 교육 |

특히 **"글자 수 × 단가"로 견적을 자동 계산하는 구조를 만들면 안 된다.**
번역에만 해당하는 방식이고, 매출의 상당 부분인 통역 · 출장 수행 · 사무국 운영이
그 공식에서 빠져버린다.

대표가 직접 밝힌 이유도 있다. 통번역 요율(글자당 단가)이 실무와 맞지 않고,
AI 초벌 번역이 일반화된 지금은 더 그렇다. 카피라이팅 한 줄에 여러 사람이 붙는 건도 있고
수백 장짜리인데 단순한 건도 있어서, **가격 공개는 위험하고 의미도 없다**는 판단이다.

## 사업 규모 (설계 판단의 근거)

- 연간 문의 **100건 미만**, 건당 규모가 큰 편
- 클라이언트 **수십 개사**
- 견적서는 **엑셀**, 세금계산서 발행 서식 기준으로 8년째 사용
- 고객 데이터는 명함 · 리멤버 등에 산재, 미정리

이 규모에서는 무거운 CRM이나 자동 견적 엔진이 과하다.
**견적서 발행 자동화가 실제 병목**이고, 고객 관리는 가벼운 도구로 충분하다.

## 과업 범위

1. **웹사이트 신규 제작** — 메뉴, 다운로드 버튼, 견적 문의, 네이버 블로그 연동, 고객 후기
2. **견적 · CRM 플랫폼 리서치** — 구축이 아니라 후보 비교 · 추천

명시적으로 **범위 밖**인 것: 영문 사이트(별도 협의), 온라인 결제, 회원 로그인, 관리자 페이지.
