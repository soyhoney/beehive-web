# 공지·소식·후기 시트

언니가 사이트 공지사항·소식·고객 후기를 직접 관리하는 흐름입니다.
시트에 한 줄 추가하면 사이트에 바로 뜹니다. Netlify 재배포 없이 즉시 반영됩니다.

## 어디에

기존 견적 접수 시트와 같은 파일. 탭 이름은 각각 **`notices`**, **`posts`**,
**`testimonials`** 로 만듭니다.
시트 URL은 `apps-script/Code.gs` 의 `SHEET_ID` 값과 일치해야 합니다.

**최초 셋업**: Apps Script 편집기에서 `setupContentSheets` 함수를 한 번 실행하면
3개 탭이 헤더·체크박스·드롭다운까지 자동으로 만들어집니다.

## 1. `notices` 탭 — 공지사항

| 열 | 이름 | 형식 | 필수 | 설명 |
|---|---|---|---|---|
| A | 번호 | 텍스트/수식 | ✕ | 표시 순서 확인용. `=ROW()-1` 수식으로 자동 매기기 권장. |
| B | 뱃지 | 드롭다운 | ✅ | **"공지"** (오렌지) 또는 **"안내"** (회색) 중 선택. 빈 값이면 안내로 처리. |
| C | 제목 | 텍스트 | ✅ | 비어 있으면 그 행은 무시됩니다. |
| D | 본문 | 텍스트 | ✕ | 1~3줄 짧은 요약. 제목 클릭 시 아코디언으로 펼쳐집니다. |
| E | 등록일 | 날짜 | ✅ | `2026-08-12` 형식 권장. 정렬에 사용됩니다. |

**정렬**: "공지" 뱃지 행이 위로 → 그다음 등록일 최신순.

### 예시

| A | B | C | D | E |
|---|---|---|---|---|
| 1 | 공지 | 웹사이트 개설을 완료하였습니다. | 안녕하세요, 비하이브코퍼레이션 웹사이트를 오픈했습니다. 문의는 service@beehivecorp.co.kr 로. | 2026-08-12 |
| 2 | 안내 | 여름 휴가 안내 | 8/12~8/16 사무실 운영이 지연됩니다. | 2026-07-28 |

## 2. `testimonials` 탭 — 고객 후기

구글 폼으로 후기를 받은 뒤, 검토한 것만 사이트에 띄우는 방식입니다.
"공개" 체크박스가 켜진 행만 노출되고, 나머지는 시트에 남아 있어도 보이지 않습니다.

| 열 | 이름 | 형식 | 필수 | 설명 |
|---|---|---|---|---|
| A | 번호 | 텍스트 | ✕ | 표시 순서 확인용. `=ROW()-1` 수식 권장. |
| B | 공개 | 체크박스 | ✅ | **체크된 행만** 사이트에 노출됩니다. |
| C | 성함 | 텍스트 | ✅ | 카드 하단에 표시됩니다. |
| D | 직함 | 텍스트 | ✕ | 예: 팀장 / 큐레이터 / PD |
| E | 소속 | 텍스트 | ✕ | 예: OO기관 / OO스튜디오 |
| F | 후기 | 텍스트 | ✅ | 200자 내외 권장. 비어 있으면 노출되지 않습니다. |
| G | 등록일 | 날짜 | ✕ | `2026-08-13` 형식. 최신순 정렬에 사용됩니다. |

**정렬**: 등록일 최신순.

### 구글 폼 → 시트 흐름

1. 언니가 구글 폼을 만들어 이메일·홈페이지·SNS 등으로 배포
2. 폼 응답은 자동으로 시트의 새 탭에 쌓임
3. 검토 후 게재할 후기만 `testimonials` 탭으로 복사 → 공개 체크
4. 사이트 새로고침 시 즉시 반영

## 3. `posts` 탭 — 소식(블로그)

| 열 | 이름 | 형식 | 필수 | 설명 |
|---|---|---|---|---|
| A | 번호 | 텍스트 | ✕ | 표시 순서 확인용. 없어도 됩니다. |
| B | 제목 | 텍스트 | ✅ | 비어 있으면 그 행은 무시됩니다. |
| C | 블로그URL | URL | ✕ | 있으면 행 클릭 시 새 탭으로 블로그 글이 열립니다. |
| D | 등록일 | 날짜 | ✅ | `2026-08-12` 형식 권장. 최신순 정렬에 사용됩니다. |

행에는 항상 옅은 골드 "소식" 뱃지가 붙습니다. 이미지는 사용하지 않습니다.

### 예시

| A | B | C | D |
|---|---|---|---|
| 1 | ICCR 16회기 사무국 운영 후기 | https://blog.naver.com/beehivecorp/... | 2026-07-15 |
| 2 | 스페인 교육부 장관 사절단 수행통역 | https://blog.naver.com/beehivecorp/... | 2026-06-22 |

## 반영 시점

- **즉시**. 사이트가 열릴 때마다 시트를 다시 읽어옵니다.
- Netlify 재배포 필요 없음. Apps Script만 정상 배포 상태면 됩니다.

## API 확인

브라우저에서 아래 주소를 열면 현재 시트 상태가 JSON으로 보입니다.

```
{NEXT_PUBLIC_QUOTE_ENDPOINT}?type=notices
{NEXT_PUBLIC_QUOTE_ENDPOINT}?type=posts
{NEXT_PUBLIC_QUOTE_ENDPOINT}?type=testimonials
```

## Apps Script 재배포가 필요할 때

이 기능(공지·소식)을 처음 켤 때 한 번만 필요합니다.

1. `apps-script/Code.gs` 를 Apps Script 편집기에 붙여넣기
2. 배포 → 배포 관리 → 편집(연필) → 새 버전 선택 → 배포
3. Netlify 재배포는 불필요 (엔드포인트 URL은 그대로)
