# 견적 문의 → 구글 시트 연결

웹사이트 견적 폼에서 보낸 데이터를 구글 시트에 쌓고, 접수 확인 메일까지 보냅니다.
서버가 필요 없어 **비용이 들지 않습니다.**

## 쌓이는 구조

시트 하나에 탭이 자동으로 만들어집니다.

| 탭 | 내용 |
|---|---|
| **전체** | 모든 문의가 공통 컬럼으로 한 줄씩 — 클라이언트 DB · 영업 현황 파악용 |
| **동행·수행 출장** | 그 구분의 문항이 그대로 컬럼이 되는 상세 표 |
| **정부·공공기관 프로젝트** | 〃 |
| **방송·행사·전문 통역** | 〃 |
| **번역·출판** | 〃 |
| **교육·트레이닝** | 〃 |
| **기타 문의** | 〃 |

한 건이 들어오면 **전체 탭과 해당 구분 탭에 동시에** 기록되고, 같은 접수번호로 묶입니다.

탭과 헤더는 첫 문의가 들어올 때 자동 생성됩니다. 미리 만들어 둘 필요가 없습니다.
나중에 폼에 문항을 추가해도 헤더 끝에 컬럼이 자동으로 붙으므로 기존 데이터가 밀리지 않습니다.

## 설치 (10분)

### 1. 시트에 스크립트 붙이기

1. 데이터를 쌓을 구글 시트를 엽니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다.
3. 기본으로 열려 있는 `Code.gs` 내용을 **전부 지우고**, 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 파일 맨 위 설정을 확인합니다.

   ```js
   const NOTIFY_TO = "info@beehivecorp.co.kr";  // 접수 알림 받을 주소
   ```

5. 저장합니다. (⌘S)

### 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴 → **웹 앱**을 선택합니다.
3. 아래처럼 설정합니다.

   | 항목 | 값 |
   |---|---|
   | 설명 | `견적 문의 접수` (자유) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > ⚠️ "모든 사용자"여야 웹사이트에서 접수가 들어옵니다.
   > 시트 자체가 공개되는 것은 아니며, 이 스크립트가 하는 일(줄 추가·메일 발송)만 열립니다.

4. **배포**를 누릅니다. 처음에는 권한 승인 창이 뜹니다.
   - "이 앱은 확인되지 않았습니다" 경고가 나오면 **고급 → (안전하지 않음) 이동**을 누릅니다.
     본인이 만든 스크립트라 정상입니다.
   - 시트 편집과 메일 발송 권한을 허용합니다.

5. 배포가 끝나면 나오는 **웹 앱 URL**을 복사합니다.
   `https://script.google.com/macros/s/AKfy.../exec` 형태입니다.

### 3. 웹사이트에 주소 넣기

프로젝트 루트에 `.env.local` 파일을 만들고 복사한 주소를 넣습니다.

```bash
NEXT_PUBLIC_QUOTE_ENDPOINT=https://script.google.com/macros/s/여기에_붙여넣기/exec
```

개발 서버를 재시작하면 적용됩니다.

```bash
npm run dev
```

### 4. 확인

1. 브라우저에서 웹 앱 URL을 그냥 열어봅니다. `{"ok":true,...}` 가 보이면 배포 성공입니다.
2. 사이트에서 견적 문의를 한 건 넣어봅니다.
3. 시트에 **전체** 탭과 해당 **구분 탭**이 생기고 줄이 쌓였는지 확인합니다.
4. 입력한 이메일로 접수 확인 메일이 왔는지 확인합니다.

## 배포 후 코드를 고쳤다면

`Code.gs`를 수정한 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 반영됩니다.
이렇게 하면 **URL이 그대로 유지**되므로 `.env.local`을 다시 고칠 필요가 없습니다.

> "새 배포"를 누르면 URL이 새로 생깁니다. 기존 URL을 유지하려면 반드시 **배포 관리**에서 수정하세요.

## 알아둘 점

- **무료 한도** — Apps Script는 하루 실행 90분, 메일 발송 100통(일반 Gmail) / 1,500통(Workspace)입니다.
  견적 문의량으로는 한참 여유가 있습니다.
- **첨부파일** — 현재는 파일 *이름만* 시트에 기록됩니다. 실제 파일은 전송되지 않습니다.
  파일까지 받으려면 Google Drive 저장을 추가해야 합니다.
- **RAW_JSON 컬럼** — 전체 탭 맨 끝에 숨겨져 있습니다. 전체 응답 원본이 들어 있어,
  나중에 실제 DB로 옮길 때 이 컬럼만으로 모든 데이터를 복원할 수 있습니다. 지우지 마세요.
- **개인정보** — 시트에 이름·연락처가 쌓입니다. 시트 공유 범위를 최소한으로 유지하세요.
